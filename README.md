# 曹双个人求职网站（GitHub Pages 版）

这是一个无需安装依赖、无需构建的纯静态网站。

## 部署方法

1. 将本压缩包全部文件解压到 GitHub 仓库根目录。
2. 提交并推送到 `main` 分支。
3. 打开仓库 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/(root)`，保存。

稍等几分钟即可通过 GitHub Pages 地址访问。

## 修改内容

- 页面内容：编辑 `index.html`
- 页面样式：编辑 `styles.css`
- 头像和简历：替换 `assets` 目录中的同名文件

本项目中的资源路径均为相对路径，同时兼容用户主页仓库和普通项目仓库。
